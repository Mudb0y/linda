# Upstream unit tests that tests/linux/rununittests.py does not run on Linux.
# A dotted name under tests.unit at the start of a line: a module or package, which is then never
# imported, or a class or single test, which is dropped after its module loads. The indented lines
# beneath it say why. "For good" marks a test of code that exists only on Windows; any other entry
# names the work that will let it run. The runner fails on an entry that matches nothing.

# For good: Windows accessibility APIs, which AT-SPI takes the place of on Linux.

tests.unit.test_UIAHandler
  For good: UI Automation is a Windows API. linuxPlatform replaces UIAHandler with a skeleton
  that has none of the names the test imports, such as getUIAUnitFromNVDAUnit.
tests.unit.test_NVDAObjects_UIA
  For good: UI Automation objects. UIAHandler.customProps does not exist on Linux, where
  UIAHandler is replaced.
tests.unit.test_UIARemoteOps
  For good: UI Automation remote operations, which run through UIARemote.dll. UIAHandler is
  replaced on Linux, so UIAHandler._remoteOps and UIAHandler.UIA do not exist.
tests.unit.test_NVDAObjects_IAccessible_ia2Web
  For good: IAccessible2 objects in web documents. IAccessibleHandler is replaced on Linux and
  does not provide IAccessibleHandler.utils, which the test imports.
tests.unit.test_orderedWinEventLimiter
  For good: the limiter for Windows WinEvents in IAccessibleHandler. IAccessibleHandler is
  replaced on Linux and does not provide orderedWinEventLimiter; Linux has no WinEvents.
tests.unit.test_excel
  For good: Microsoft Excel objects, reached in process through nvdaHelperLocal.dll. The Linux
  NVDAHelper.localLib has no EXCEL_CELLINFO, which the test imports.

# For good: other Windows-only subsystems.

  For good: builds the exception from _ctypes.COMError, which exists only on Windows.
tests.unit.test_visionEnhancementProviders.test_magnificationAPI
  For good: calls MagInitialize in Magnification.dll, the Windows Magnification API behind the
  screen curtain.
tests.unit.test_winVersion.TestWinVersion.test_getWinVer
  For good: compares winVersion.getWinVer() with sys.getwindowsversion(), which exists only on
  Windows.
tests.unit.test_winVersion.TestWinVersion.test_winVerProcessorArchitecture
  For good: reads the PROCESSOR_ARCHITECTURE environment variable, which Windows sets.
tests.unit.test_winBindings_icu
  For good: tests how upstream's winBindings.icu finds icu.dll or icuuc.dll through windll.
  linuxPlatform replaces winBindings.icu with a binding that loads ICU by path from
  BASEDREADER_ICU_LIB_DIR, which test_nativeHelper.py tests.
tests.unit.test_installer.Test_BatchDeletion.test_deleteFilesFailure
  For good: expects deleting a file that is open to fail, as it does on Windows; Linux deletes it.
tests.unit.test_addonHandler.test_addonImports.TestCleanupAddonImports.test_addonModuleRemovedRegardlessOfPathCase
  For good: expects paths that differ only in case to name the same file, as on Windows. On Linux
  they are different files, so keeping the module is right.
tests.unit.test_textUtils.test_backendComparison.TestWordOffsetsComplexScriptDivergence
  For good: asserts where Uniscribe's word breaks differ from ICU's for Japanese and Khmer.
  Uniscribe is a Windows library; on Linux the UNISCRIBE word segmenter is ICU too, through
  NVDAHelper.localLib, so the two agree.
tests.unit.test_textUtils.test_backendComparison.TestWordOffsetsEmojiZwjSequence.test_backends_diverge
  For good: asserts that Uniscribe breaks an emoji ZWJ sequence where ICU does not; on Linux both
  segmenters are ICU.
tests.unit.test_textUtils.test_backendComparison.TestMixedSpacesAndTabs.test_spacesThenTabs
  For good: asserts that Uniscribe separates spaces from the tabs after them; on Linux both
  segmenters are ICU, which keeps the run whole.

  calculateCharacterOffsets.
