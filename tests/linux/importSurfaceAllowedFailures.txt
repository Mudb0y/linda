# Modules under source/ that are allowed to fail to import on Linux.
# Module names start a line; an indented line gives the reason for the
# modules listed above it, back to the previous reason.
# test_importSurface.py fails when a module not listed here fails to
# import, and when a module listed here imports.
#
# A module that imports cleanly can still import one of these later,
# inside a function. Each such module is named under the reason, on a
# line starting "reached from", followed by "safe" or "not safe" and why.
# The test fails when such a module is not named, and when a module named
# no longer imports any module of that group.
