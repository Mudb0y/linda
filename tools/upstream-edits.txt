# Each reason starts with the kind of edit, which says what a merge risks,
# and an entry with edits of several kinds starts a line with each:
#   import safety: Windows-only work done at import is done only on Windows
#   Linux runtime: what the code does differently when it runs on Linux
#   every platform: a change in the code Windows runs, beyond its tests of
#     sys.platform, even where Windows ends up doing the same
#   repository: a file that is not NVDA's code
# For a Python file, the check works out from the code whether Windows runs
# a change, and fails unless every platform is said exactly when it does.
