source/NVDAObjects/window/winword.py
  import safety: RegisterWindowMessage at module level runs only on Windows;
  documentNavigation.paragraphHelper, which kept code uses, imports winword.
  On Linux wm_winword_expandToLine is absent; nothing reads it
source/NVDAState.py
  import safety: winreg imported only on Windows, after the module's other
  imports so that upstream's import block stays whole. On Linux winreg is
  absent, so each registry reader here raises NameError when called,
  including _forceSecureModeEnabled and _serviceDebugEnabled, which
  nvda.pyw calls at start-up; their Linux answers are A2's to decide
source/_remoteClient/localMachine.py
  import safety: winreg imported only on Windows, after the module's other
  imports; the SAS policy's registry key class attribute is defined only
  there, so on Linux SoftwareSASGeneration.KEY is absent and reading the SAS
  policy raises AttributeError
source/_remoteClient/urlHandler.py
  import safety: winreg imported only on Windows, after the module's other
  imports; the one annotation that names it is quoted so it is not
  evaluated at import. On Linux winreg is absent, so registering the URL
  handler raises NameError
source/browseMode.py
